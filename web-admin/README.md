# DSH Feishu Admin (management-only companion)

This package adds a native **飞书管理** operations workbench to DSH Web's left sidebar, including an **Agent 档案** file manager, and keeps a separate **飞书 Gateway** credential-only page in Settings. The Agent files view is a responsive two-pane file explorer and full-width source editor with edit/preview/history/loading tabs, quick save, and unsaved-draft safeguards. Source editing uses safe Markdown syntax coloring, a toggleable numbered gutter, an active-line indicator, and cursor positions without a CDN or an additional code-editor dependency.

- The **web** Profile only loads this admin package; it never creates Feishu WebSockets or DSH Agent Sessions.
- The existing **feishu-channel** Profile continues to host the real Feishu gateway.
- API: `/api/feishu-admin/{state,health,diagnostics,ops,ops/events,ops/commands,config,credentials,restart}` using DSH `webServer` / `connection.requestRejection`. Read endpoints return redacted runtime DTOs, while command writes are strictly limited to cancel-running-task or durable Outbox re-drain.
- No additional HTTP listener or exposed port. Same-origin cookies and non-GET request headers are required.
- Browser UI uses the official `sidebar.panellist` and root-scoped `main` slots for the workbench; `settings.section` / `settings.section.icon` remain for the credential-only form. Both use `ctx.slots.inject` to handle load/unload ordering.
- Workbench views: overview, active tasks, message lifecycle, native Session bindings, approval audit, model/bot usage, current alerts, WebSocket diagnostics, permissions and editable advanced configuration. Operations data is generated by Gateway rc.5 as privacy-safe snapshots/events; raw chats are never fetched.
- Changes are written atomically to `~/.dsh/feishu-channel-state/admin-config.json` (0600) and loaded by the real gateway **on restart**.
- Feishu App Secret is **write-only** and is stored in `~/.dsh/feishu-channel.env` (0600); never returned to browser clients.
- Restart is limited to `systemctl --user restart dsh-feishu-channel.service` (not arbitrary command execution).

## Historical token analytics (Issue #17)

The existing Usage view now reads a separate protected, append-only per-task usage ledger with model-reported input/output/cache tokens; absent provider usage is explicitly unknown. New authenticated routes: /ops/usage and /ops/usage/export (CSV). UI includes a calendar heatmap, day/week/month trends, IANA time zone, model/bot/hashed user/chat/Session filters and CSV. See [../docs/TOKEN-USAGE-ANALYTICS.md](../docs/TOKEN-USAGE-ANALYTICS.md). This branch is not yet a published release or tenant acceptance.

## Current constraints

The admin service and channel service must run as the same Unix user on the same host, or share access to the configured state and credentials paths. The channel host must expose its pre-existing loopback `/health` and `/diagnostics` endpoints on port 18095. The admin API does not parse or rewrite the user's Profile YAML; settings omitted in the managed overlay continue to inherit from it.

## 统一工作台导航（Gateway 管理）

Web Admin 按真实网关能力而不是接口数量组织导航：

- **会话与消息**：实时任务、Inbox/Outbox 消息状态、Session 绑定及批量管理
- **定时任务**：原生 DSH Schedule、运行结果与飞书通知
- **接入与权限**：机器人设置、群聊规则、私聊白名单、沙箱及审批策略
- **Agent 档案**：独立工作区、身份、指令文件及历史
- **用量与审计**：Token 趋势与工具审批审计
- **运维与诊断**：健康告警、WebSocket 状态及结构化日志
- **模型与连接**：从飞书通道的 DSH Profile 读取 Provider/模型目录，显式选择主模型与 Fallback 模型（不再使用“留空继承”）；网络代理、消息卡片、超时及重试参数

同类功能在分组内通过次级标签切换，移动端主导航和次级标签支持横向滚动。凭据独立保存在 DSH 设置，不在监控界面回显。配置变更需要按提示重启 Gateway。
