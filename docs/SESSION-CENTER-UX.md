# 飞书会话管理：对话、归档与回收站

入口：**DSH Web → 飞书管理 → 会话与消息 → 会话管理**，排在“实时任务”和“消息投递”前面。

## 页面结构

| 页面 | 操作 |
| --- | --- |
| **对话历史** | 只显示未归档、未移入回收站的会话；搜索、归档或移入回收站 |
| **回收站 → 已归档** | 显示隐藏在 DSH 常用侧栏的历史；可恢复或移入回收站 |
| **回收站 → 回收站** | 显示待处理会话、移入时间、恢复操作；不等于已删除 |
| **回收站 → 自动整理规则** | 设置 90 天自动归档候选条件和 30 天回收站期限 |
| **回收站 → 高级设置** | 设置飞书工作区自动归位、任务失联宽限时间和预览 |
| **飞书聊天关联** | 查看哪些飞书聊天连接到某段 DSH Session；可隐藏或解除关联 |

技术 ID、机器人 ID 和聊天引用放在“查看技术信息”中，默认显示会话标题、来源、时间和可验证的状态。

## 操作会发生什么？

| 操作 | DSH 历史 | 是否可恢复 | 是否释放磁盘 |
| --- | --- | --- | --- |
| 归档 | 保留；从常用列表隐藏 | DSH 支持原生取消归档时可恢复 | 否 |
| 移入回收站 | 保留；利用原生归档隐藏，记录暂存状态 | 是，要求 DSH 支持恢复接口 | 否 |
| 从回收站恢复 | 返回移入前的“对话历史”或“已归档”状态 | 已恢复 | 否 |
| 解除飞书关联 | 保留历史；下一条飞书消息会新建 Session | 不会自动恢复原聊天关联 | 否 |
| 永久删除 | **未实现** | — | **不可用** |

**“未关联”不等于可删除。** 目前暂存仅允许没有飞书关联、没有活动定时任务引用、未运行且状态可以确认的历史；仍然被使用的 Session 会被拒绝。

### 为什么回收站到期不会自动清空？

DSH 的 `ctx.sessionPersistence` **没有官方通用删除/保留期 API**。因此本插件仅能安全进行“回收站暂存与恢复”，不能直接删除原生日志文件。回收站 **30 天**表示到期管理期限与候选统计，不会在第 30 天自动物理删除。永久删除和自动删除的开关保持不可用，不会假报磁盘空间已释放。物理清理仍在 [Issue #37](https://github.com/WeipengMO/dsh-plugin-feishu-gateway/issues/37)。

## 90 天自动归档策略

- 初始值为 **90 天未使用**；为保护现有历史，**自动归档开关默认关闭，需要明确启用**。
- 启用后，每小时进行一次候选检查，只有**已可靠记录最后活动时间**、当前未关联/未运行、非定时任务、未归档/未在回收站的会话可以尝试归档。
- 如果只知道原生 Header 创建时间而不知道最后活动时间，将标为“最近活动未记录”并**排除自动归档**；不会把创建时间误当作闲置依据。
- Gateway 状态过期、消息未投递、工具审批尚在进行、DSH 原生工作区不支持安全归档时，不进行自动归档。
- 自动归档**不等于**自动移入回收站、自动删除或释放磁盘空间。

## 飞书工作区自动整理

这是另一个独立功能：它决定哪些原生 Session 在 DSH 的“飞书会话”工作区显示，不会改变 Session 正文，也不会把原来的 `cwd` 强行改写。高级设置默认折叠；建议先预览将归位的记录，再明确启用。详见 [工作区整理技术说明](FEISHU-SESSION-ORGANIZATION.md)。

## 安全与验收

- 原生归档、回收站暂存使用受认证保护的 Web 管理 API，并在执行前重新确认会话是否仍可操作。
- 回收站暂存通过 30 秒一次性预览令牌确认；重复提交或过期令牌不会产生新操作。
- 记录暂存时间和原先是否归档，恢复后不改变飞书聊天关联。
- 不直接读取/删除 DSH 底层压缩日志，不调用 `Agent.resume`，不抢占 Gateway writer。
- 真实 DSH Host 还需核验归档、暂存、恢复后的 Session ID 和对话正文不变；自动化 Mock 测试不能取代实际部署测试。

技术接口见 [Session 生命周期](SESSION-LIFECYCLE.md)，后续真实删除能力见 [Issue #37](https://github.com/WeipengMO/dsh-plugin-feishu-gateway/issues/37)。
