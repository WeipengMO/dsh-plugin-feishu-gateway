# 飞书会话管理：对话历史与已归档

入口：**DSH Web → 飞书管理 → 会话与消息 → 会话管理**。

## 页面

| 页面 | 可以做什么 |
| --- | --- |
| **对话历史** | 每条会话都有「归档」入口；勾选多条后可「批量归档」，归档成功后出现在「已归档」 |
| **已归档** | 单条「恢复 / 删除」，勾选多条后可「批量恢复 / 批量删除」，不再嵌套「回收站」页 |
| **飞书聊天关联** | 处理飞书聊天到 DSH Session 的关联，不操作聊天正文 |

旧版曾经移入回收站的记录会继续在「已归档」中显示；恢复时依据原先状态恢复，不丢失历史。自动归档与飞书工作区归位设置都放在已归档页面下面，高级选项默认折叠。

## 归档、恢复和删除

- **归档**只是把 DSH 会话从常用侧栏隐藏。原始日志仍在，**不会回收磁盘空间**。
- **恢复**将 DSH 会话重新显示，历史不变；不自动恢复已经解除的飞书聊天关联。
- **删除**要求具备可验证的 **DSH 安全删除服务**，并在后台页面内确认，勾选不可恢复声明后才执行。它会真正删除原生存储，而不是简单地隐藏或解除绑定。
- **没有安装可选的 `@michengai/dsh-archive-manager` 或未成功加载其删除接口时**，「删除」按钮保持灰色并说明原因；归档与恢复不受影响。官方 `ctx.sessionPersistence` 没有通用 delete API，本项目不会自行 `rm` 原生日志。
- 当前仅允许删除**已归档、未关联、非定时任务、非活动中、无待审批/待投递消息**的会话。操作前后都校验，失败时不宣称成功。

**永久删除是可选增强功能，不是飞书插件的必需依赖。**

当前支持通过 [@michengai/dsh-archive-manager](https://github.com/MichengAI/dsh-archive-manager) 提供永久删除。它在 DSH `web` Profile 的 `workspaceRegistry` 上增加 `archivedSessionMetadata()`、`deleteArchivedSessions()` 和 `deleteSession(sessionId)` 接口，而**不是**单独的 `sessionAdmin` 服务。

- **未安装或未启用**：后台「删除」按钮灰色，归档、恢复、会话搜索等功能照常使用。
- **已安装并加载，且 Gateway 状态安全**：符合条件的已归档会话可点击「删除」，二次确认后调用原生 `workspaceRegistry.deleteSession(sessionId)`，不是单纯解绑或隐藏。
- **即使接口已加载**，运行中、仍有飞书关联、属于定时任务或无法确认安全状态的会话仍不允许删除。

仅当你想要永久删除时，可选在管理端所属的 DSH Web Profile 安装：

```bash
dsh plugin --profile web add @michengai/dsh-archive-manager
dsh --profile web --dump-config
```

如果安装后按钮仍为灰色，请检查插件是否在 **`web` Profile** 中启用、DSH Web 是否已重新加载插件、Gateway 状态是否可用，以及当前会话是否符合删除条件。此插件不需要安装在 `feishu-channel` Profile。**目前仅核对了上游源码接口；在你的真实 DSH 环境中的成功调用仍需实机验收。**

## 多选与批量操作

在「对话历史」或「已归档」中，可勾选每条记录，或使用列表上方的 **「选择本页」**、**「清空选择」**。支持跨页累计选择，每次最多 **20 条**。选择会在更改搜索条件时清空，避免误操作隐藏记录。

- **对话历史 → 归档 / 批量归档**：需要会话目前未归档、未关联飞书聊天、不是定时任务、运行状态可确认。每条都显示「归档」按钮；不符合条件时呈灰色，悬停可查看原因。不会自动解除飞书聊天关联。
- **已归档 → 恢复 / 批量恢复**：恢复到正常对话列表，原生日志保留；历史遗留的旧回收站暂存记录也能恢复。
- **已归档 → 删除 / 批量删除**：仅在可选 `@michengai/dsh-archive-manager` 删除接口已加载且会话安全时可操作；否则按钮保持灰色。真正删除不可恢复，支持批量时仍需要危险操作确认。

批量提交前后台会先计算符合条件和跳过的数量，并列出主要跳过原因；确认后服务端逐条重新检查。只有**实际成功**的记录才计入成功结果；状态变化或不符合条件的记录会跳过，并显示汇总。所有确认均采用飞书 Web Admin **页面内弹窗**，不使用浏览器原生确认框。

## 页面内确认弹窗

归档、恢复、删除、飞书聊天关联的隐藏/解除、批量处理，以及工作区整理和启用自动归档，都使用飞书管理页面内弹窗。永久删除要求额外勾选确认，不再调用浏览器原生 `window.confirm`。会话名称、删除风险与是否释放空间会以正常中文展示。

## 自动归档和删除期限

- 默认建议 **90 天不活跃自动归档**，但开关初始关闭，开启前需确认。
- 只使用可靠记录的最后活动时间；只有创建时间而无法确认最后活动日期的会话会跳过。
- **自动永久删除仍默认关闭且不可用**。删除是不可逆操作，不能因为历史时间超过阈值就擅自清理。
- 旧版 30 天回收站保留设置在数据层保留以兼容历史配置，但不再作为一个二级页面或自动删除规则展示。

## 安全细节

Web 管理通过 DSH 原有认证。永久删除请求先生成 **30 秒有效且只能消费一次**的令牌；执行时重新检查会话仍归档、未绑定、无活跃任务和最新 Gateway 状态，并交由安全删除服务处理日志、工作区和相关索引。返回实际清理字节数时才展示；不会凭估算值宣称已释放空间。

开发及详细数据边界见 [Session 生命周期](SESSION-LIFECYCLE.md) 与 [Issue #37](https://github.com/WeipengMO/dsh-plugin-feishu-gateway/issues/37)。
