# 飞书管理后台使用指南

管理后台位于 **DSH Web 左侧栏 → 飞书管理**。首次部署和双 Profile 安装见 [首次部署](GETTING-STARTED.md)，服务维护见 [运维手册](OPERATIONS.md)。

## 页面导航

| 页面 | 可以做什么 |
| --- | --- |
| **总览** | 查看机器人连接、运行统计和关键异常 |
| **会话与消息 → 会话管理** | 查看 DSH 对话历史、已归档的恢复/安全删除、90 天自动归档设置和飞书聊天关联 |
| **会话与消息 → 实时任务** | 查看当前 Agent 执行，允许时请求取消 |
| **会话与消息 → 消息投递** | 检查消息接收、处理、发送及失败状态 |
| **定时任务** | 创建/编辑/暂停/立即执行任务、查看结果及飞书通知 |
| **接入与权限** | 设置机器人、群聊策略、私聊白名单、工具执行权限 |
| **Agent 档案** | 编辑飞书 Agent 身份、提示规则和记忆文件、预览及恢复历史版本 |
| **用量与审计** | 查看 Token 用量、模型趋势和审批历史 |
| **运维与诊断** | 告警、连接状态、结构化日志与管理命令结果 |
| **模型与连接** | 主模型和备用模型、**Agent 预设（飞书工作模式）**、代理、卡片、超时和重试配置 |

飞书应用的 **App ID / App Secret** 等凭据配置放在 **DSH Web 设置 → 飞书 Gateway**；秘密不在普通业务看板中回显。

### 导航与操作反馈

左侧导航按「日常管理」「机器人与 Agent」「统计与诊断」分组；手机和窄工作区下使用可横向滚动的导航。总览将服务状态、任务与告警放在快捷入口之前，便于先判断是否需要处理异常。

编辑机器人、群聊、执行权限、模型配置、Agent 档案、Skills 或定时任务时，如果有未保存内容，切换导航或关闭页面应提示确认。定时任务的创建/编辑请求如果未被 Gateway 接受，表单保留原来的任务内容，避免重新填写。**保存成功**不代表**已在运行的飞书通道生效**；涉及重启的配置仍需等待新进程加载。

Token 用量页的开始和结束日期位于同一个「日期范围」控件组；图表根据 DSH 实际内容宽度布局，即使浏览器宽度不变而侧栏展开，也能切换紧凑布局。日历热图可悬停、键盘聚焦或触摸点按查看明细，点按后可以主动关闭。模型与机器人用量条直接显示数值，不必只依赖悬停。

### 视觉与响应式验收

建议在常见桌面宽度（1440 / 1024 px）、平板（768 px）和手机（390 px）检查所有页面，并在浏览器缩放到 125% / 150%、DSH 左右侧栏同时展开时额外检查模型编辑、用量图表、长表格和会话列表。长运维表格允许在容器内横向滚动，不应令整个页面溢出。

回归执行：

```bash
pnpm run build
pnpm run test
pnpm --dir web-admin test
```

前端代码测试和 CI 不等同于真实 DSH Web 浏览器验收；部署后仍应验证交互、暗色主题和飞书通道重启后的实际生效状态。


## 机器人管理：连接状态与配置来源

进入 **接入与权限 → 机器人**，首先可以查看机器人标识、连接状态、接入区域、是否启用、凭据是否配置，以及**脱敏后的 App ID**。点击「检查连接状态」只读取当前 Gateway 报告的长连接健康状态，**不会向飞书发送消息**，也不等于完成真实收发验收。App Secret 始终不会回显。

**配置来源**提供两种模式：

- **使用 DSH 原有配置（默认）**：不在管理文件中写入机器人列表覆盖项，保留已有配置来源。当前已经能够收发消息时，通常不需要切换。
- **在此页面管理**：切换后可添加、编辑、禁用或移除机器人（最多 8 个），会由页面保存的机器人列表覆盖原有列表。切换前有页面内确认弹窗。

保护规则：托管列表不能保存为空，不能全部禁用，也不能使用相互冲突的机器人标识（例如 `a-b` 和 `a_b`）；服务端同样会拒绝这些危险写入。切换回 DSH 原有配置时，只移除机器人列表覆盖项，**不删除** App ID、App Secret、模型、代理及访问策略。保存后需要在维护窗口**手动重启**飞书通道才会应用，页面不会自动中断正在运行的 Agent 任务。

机器人标识是 Gateway 的配置 ID，不代表自动读取的飞书应用展示名称。新机器人还需要在 **DSH 设置 → 飞书 Gateway** 配置对应凭据，才可能正常连接。

## 会话管理：不要把不同操作混在一起

- **对话历史**：DSH 保存真正的 Session；每条会话显示「归档」，符合条件时可点击，或勾选多条执行「批量归档」。仍有关联、运行中或定时任务会话的按钮灰色，避免错误隐藏。
- **已归档**：一张列表直接提供「恢复 / 删除」，并支持多选后的「批量恢复 / 批量删除」（单次最多 20 条）；后台逐条检查，显示成功和跳过结果。删除使用**可选**的 `@michengai/dsh-archive-manager`，未安装、未启用或不符合安全条件时按钮为灰色；不影响归档与恢复。
- **飞书聊天关联**：一段飞书聊天继续对应哪个 DSH Session。解除关联后下一条消息会创建新对话，但旧历史不被删除。
- **自动整理与高级设置**：已归档页面下保留 90 天自动归档（需主动启用）和折叠的工作区整理配置。旧回收站记录仍显示在“已归档”中；自动永久删除仍不可用（[Issue #37](https://github.com/WeipengMO/dsh-plugin-feishu-gateway/issues/37)）。

界面默认应以标题/来源/状态为主；ID 和哈希只在技术详情出现。更多见 [会话管理详细说明](SESSION-CENTER-UX.md)。

## 哪些设置需要重启？

机器人连接、模型路由、代理及部分持久管理配置通常在 **Gateway 启动时加载**。保存后请核对页面提示，并在无在途任务的维护窗口重启独立的飞书通道。不要因为 Web Admin 页面可打开，就认为 Gateway 一定加载了最新配置。

- **主模型**：从 Gateway Host 当前可发现的模型中选择，不必先选择 Provider。
- **Agent 预设（飞书工作模式）**：从 Gateway Host 的 DSH 预设计划中选择一个作为新会话的工作模式；已有会话在创建时已固定模式，需 `/new` 切换。详见 [Agent 预设](AGENT-PRESET-SELECTION.md)。
- **备用模型**：同一个多选框中添加/移除，按顺序回退；执行过工具的请求不会被自动重试，防止重复副作用。
- **群聊**：默认不开放，需明确启用策略、成员白名单，通常建议要求 @机器人。
- **定时任务**：依赖 DSH `ctx.schedule` 原生服务；不可用时不伪造本地 Cron。
- **工作区自动整理**：默认关闭；确认预览后再启用，不会删除 DSH 历史。

## 管理操作如何确认结果

- “请求已提交”“已排队”**不等于执行成功**。Gateway 会再次检查活动任务、未处理 Inbox、审批、Outbox、绑定版本及权限。
- 部分批量操作可能有成功、跳过和失败三类结果；到 **运维与诊断 → 告警中心** 看执行记录。
- 归档、解除关联、取消任务都**不会撤销已经执行的外部工具操作**。
- 如果 Gateway 离线、快照过期或 DSH 不提供所需接口，后台应该禁用高风险操作并解释原因，而不是假成功。会话管理确认统一使用页面内弹窗，永久删除必须额外确认不可恢复。

## 安全边界

后台请求使用 DSH 原生用户认证和同源/CSRF 保护，写入使用受限数据结构和独立管理权限。Admin 不读取或回显 App Secret，不创建第二个 Agent Host，也不主动删除原生 DSH Session 文件。详细实现可查 [技术架构](ARCHITECTURE.md) 和 [开发测试](DEVELOPMENT.md)。
