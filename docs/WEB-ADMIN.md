# 飞书管理后台使用指南

管理后台位于 **DSH Web 左侧栏 → 飞书管理**。首次部署和双 Profile 安装见 [首次部署](GETTING-STARTED.md)，服务维护见 [运维手册](OPERATIONS.md)。

## 页面导航

| 页面 | 可以做什么 |
| --- | --- |
| **总览** | 查看机器人连接、运行统计和关键异常 |
| **会话与消息 → 会话管理** | 查看 DSH 对话历史、已归档的恢复/安全删除、90 天自动归档设置和飞书聊天关联 |
| **会话与消息 → 实时任务** | 查看当前 Agent 执行，允许时请求取消 |
| **会话与消息 → 消息投递** | 检查消息接收、处理、发送及失败状态 |
| **定时任务** | 创建/编辑/暂停/立即执行任务、查看结果及飞书通知 |
| **接入与权限** | 设置机器人、群聊策略、私聊白名单、工具执行权限 |
| **Agent 档案** | 编辑飞书 Agent 身份、提示规则和记忆文件、预览及恢复历史版本 |
| **用量与审计** | 查看 Token 用量、模型趋势和审批历史 |
| **运维与诊断** | 告警、连接状态、结构化日志与管理命令结果 |
| **模型与连接** | 主模型和备用模型、代理、卡片、超时和重试配置 |

飞书应用的 **App ID / App Secret** 等凭据配置放在 **DSH Web 设置 → 飞书 Gateway**；秘密不在普通业务看板中回显。

## 会话管理：不要把不同操作混在一起

- **对话历史**：DSH 保存真正的 Session；可以搜索历史，符合条件的未关联旧会话可归档。
- **已归档**：一张列表直接提供“恢复”和“删除”。删除使用**可选**的 `@michengai/dsh-archive-manager`，未安装、未启用或不符合安全条件时按钮为灰色；不影响归档与恢复。没有回收站二级切换。
- **飞书聊天关联**：一段飞书聊天继续对应哪个 DSH Session。解除关联后下一条消息会创建新对话，但旧历史不被删除。
- **自动整理与高级设置**：已归档页面下保留 90 天自动归档（需主动启用）和折叠的工作区整理配置。旧回收站记录仍显示在“已归档”中；自动永久删除仍不可用（[Issue #37](https://github.com/WeipengMO/dsh-plugin-feishu-gateway/issues/37)）。

界面默认应以标题/来源/状态为主；ID 和哈希只在技术详情出现。更多见 [会话管理详细说明](SESSION-CENTER-UX.md)。

## 哪些设置需要重启？

机器人连接、模型路由、代理及部分持久管理配置通常在 **Gateway 启动时加载**。保存后请核对页面提示，并在无在途任务的维护窗口重启独立的飞书通道。不要因为 Web Admin 页面可打开，就认为 Gateway 一定加载了最新配置。

- **主模型**：从 Gateway Host 当前可发现的模型中选择，不必先选择 Provider。
- **备用模型**：同一个多选框中添加/移除，按顺序回退；执行过工具的请求不会被自动重试，防止重复副作用。
- **群聊**：默认不开放，需明确启用策略、成员白名单，通常建议要求 @机器人。
- **定时任务**：依赖 DSH `ctx.schedule` 原生服务；不可用时不伪造本地 Cron。
- **工作区自动整理**：默认关闭；确认预览后再启用，不会删除 DSH 历史。

## 管理操作如何确认结果

- “请求已提交”“已排队”**不等于执行成功**。Gateway 会再次检查活动任务、未处理 Inbox、审批、Outbox、绑定版本及权限。
- 部分批量操作可能有成功、跳过和失败三类结果；到 **运维与诊断 → 告警中心** 看执行记录。
- 归档、解除关联、取消任务都**不会撤销已经执行的外部工具操作**。
- 如果 Gateway 离线、快照过期或 DSH 不提供所需接口，后台应该禁用高风险操作并解释原因，而不是假成功。会话管理确认统一使用页面内弹窗，永久删除必须额外确认不可恢复。

## 安全边界

后台请求使用 DSH 原生用户认证和同源/CSRF 保护，写入使用受限数据结构和独立管理权限。Admin 不读取或回显 App Secret，不创建第二个 Agent Host，也不主动删除原生 DSH Session 文件。详细实现可查 [技术架构](ARCHITECTURE.md) 和 [开发测试](DEVELOPMENT.md)。
